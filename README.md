# بلوچستاننما — BalochistanNama 🌴

اپلیکیشن اندرویدی وب‌محور (Capacitor) برای مردم بلوچستان و علاقه‌مندان به فرهنگ بلوچی.

> تقویم سه‌گانه، اوقات شرعی اهل سنت، هواشناسی پیشرفته با هشدار گردوغبار، اذان مکه، تسبیح دیجیتال، فرهنگ و ادبیات بلوچی، یادگیری زبان بلوچی و بیشتر...

---

## ✨ امکانات

### 📅 تقویم سه‌حالته
- **شمسی** (فارسی) — با فاز ماه 🌑🌒🌓🌔🌕🌖🌗🌘 کنار هر روز
- **میلادی** (Gregorian)
- **قمری** (Hijri) — با شمارش معکوس مناسبت‌های اسلامی (عاشورا، میلاد پیامبر، نیمه شعبان، رمضان، شب قدر، عید فطر، عرفه، عید قربان و...)
- مبدل تاریخ سه‌طرفه
- **پرش به مناسبت** با جستجوی سراسری ۱۲ ماه
- تاریخ و مناسبت‌های هر روز با یک تپ

### 🕌 اوقات شرعی
- **روش‌های اهل سنت**: کراچی، مȣلا حسن ندیم، مȣلا جان، شفیعی و...
- محاسبه دقیق ۶ اوقات شرعی (اذان صبح، طلوع، ظهر، عصر، مغرب، عشاء)
- **نصیحت قبله** با قطبنما و راهنمای جهت

### 🌙 اذان مکه مکرمه
- **اذان دیجیتال** با Web Audio API (سه سبک: استاندارد، آهسته، گرم)
- پخش نت‌های واقعی اذان با ویبراتو

### 📊 اعلان همیشگی
- اعلان دائمی اوقات شرعی در نوار وضعیت
- نمایش نماز بعدی + ساعت + شهر
- قابل تنظیم از تنظیمات برنامه

### 🌦️ هواشناسی پیشرفته
- **کیفیت هوا**: PM2.5، PM10، غبار
- **تندباد و گردوغبار**: هشدار خودکار (دسته ۳۰-۳۸ + PM10 > ۱۵۰)
- **پیش‌بینی ساعتی ۱۲ ساعت**
- **وضعیت آفلاین**: کش خودکار آخرین وضعیت هوا
- پشتیبانی از ۲۰ شهر سیستان و بلوچستان (چابهار، ایرانشهر، زاهدان، خاش، سراوان، کنارک، نیکشهر، مهرستان، فنوج، بخش‌های لاشار، رمشک، دشتیاری و...)

### 🧭 ابزارها
- **قطبنما** (compass)
- **خلبان‌نمای HUD** — طراحی سبک کابین با نوار heading، قوس bank، pitch ladder، نماد هواپیما
- **تسبیح دیجیتال**
- **مناسبت‌های امروز و فردا** در اعلان

### 🏠 ساعت خانه
- ساعت دیجیتال بزرگ با تاریخ شمسی
- امکان فعال/غیرفعال کردن ساعت تابستانی

### 🗓️ تقویم گوشی
- افزودن مستقیم مناسبت‌ها به تقویم دستگاه

### 🎭 فرهنگ بلوچی
- **۲۶ مناسبت بلوچی**: سیت، سوج، لوک مهمونی، مهرگان بلوچی، هانی بلوچ، شهداد کمال، دهاندار، روز براهوئی، روز مکران و...
- شعر و ادبیات بلوچی با امکان اشتراک‌گذاری تصویری
- ضرب‌المثل‌های بلوچی
- داستان‌های بلوچی و تاریخچه

### 🗣️ یادگیری زبان بلوچی
- ۴۰ واژه روزمره + ۱۷ جمله پرکاربرد
- آزمون حدس معنی

### 🎵 روزه
- ۵۹۴ سؤال و جواب فقهی از کتاب «روزه» دکتر راشد سعد العلیمی
- جستجوی سراسری در سؤالات

### 👨‍👩‍👧‍👦 خانوادگی
- ثبت تولدها و سالگردها
- نمایش سن شمسی در تقویم 🎈
- نقطه بنفش روی روزهای دارای مناسبت خانوادگی

### 📝 یادداشت‌ها
- ثبت یادداشت با تاریخ شمسی
- نمایش در جزئیات روز تقویم

### ⚙️ تنظیمات
- شهر و مختصات جغرافیایی
- روش محاسبه اوقات شرعی
- زبان و فونت
- حالت شب/روز

## 🛠️ فناوری‌ها

| لایه | تکنولوژی |
|------|-----------|
| رابط کاربری | HTML + CSS + JavaScript (SPA) |
| کانتینر اندروید | [Capacitor](https://capacitorjs.com/) |
| کد نیتیو | Java (اعلان، ویجت، تقویم گوشی) |
| محاسبات تاریخ | جلالی + میلادی + هجری قمری (خودکار) |
| محاسبه نماز | الگوریتم Astronomical + روش‌های اهل سنت |
| هوا | Open-Meteo API (رایگان، بدون نیاز به کلید) |
| اذان | Web Audio API (تولید صدا در لحظه) |

## 📱 نصب

1. فایل APK را دانلود کنید
2. از **تنظیمات گوشی → امنیت → ناشناخته** اجازه نصب بدهید
3. APK را نصب کنید
4. شهر خود را انتخاب کنید (پیش‌فرض: لاشار، چابهار)

## 🔧 توسعه

اگر می‌خواهید در توسعه مشارکت کنید:

```bash
# کلون کردن
git clone https://github.com/msmarbabi/balochistan-nama.git

# نصب وابستگی‌ها
npm install

# ساخت اندروید
npx cap sync android
npx cap open android
```

## درباره

**بلوچستاننما** یک اپلیکیشن وب‌محور اندرویدی است که با هدف خدمت به مردم سیستان و بلوچستان، به‌ویژه منطقه لاشار و چابهار، ساخته شده است. این برنامه تقویم شمسی/میلادی/قمری، اوقات شرعی با روشهای اهل سنت، هواشناسی با هشدار گردوغبار، و فرهنگ بلوچی را در یک برنامه ساده و زیبا گرد هم آورده است.
