# 🕌 بلوچستان نما (Balochistan Nama)

یک اپلیکیشن موبایل (اندروید) جامع برای تقویم، اوقات شرعی، هواشناسی، فرهنگ بلوچی و ابزارهای مذهبی — با رابط کاربری کاملاً فارسی/بلوچی و قابلیت کار آفلاین.

> نسخه فعلی: **۱.۵** — بسته (`package`): `ir.balochistan.nama`

---

## ✨ ویژگی‌های اصلی

### 📅 تقویم سه‌گانه
- نمایش **شمسی (جلالی)**، **قمری (هجری)** و **میلادی** هم‌زمان
- نقطه‌های رنگی رویدادها طبق دسته‌بندی (تعطیل رسمی / بلوچی / سنت / شیعه / جهانی)
- نوار رنگی فصل‌ها (بهار ☀️ / تابستان / پاییز / زمستان) + ایموجی فصل کنار نام ماه
- رویدادهای محلی **سیستان و بلوچستان** (روزهای بومی، مناسبت‌های استانی)
- جستجوی مناسبت‌های روز / ماه
- تبدیل تاریخ بین سه تقویم + اشتراک تصویر تاریخ روز (خروجی تصویر)

### 🕌 اوقات شرعی و قبله
- محاسبه اوقات شرعی (۵ وقت + نیم‌النهار) با چندین **روش محاسباتی** (تهران، کراچی، مکه، ام‌القری، شمال آمریکا ISNA و…)
- **تنظیم دستی نماز**: همه اوقات با هم، هر وقت به‌صورت تکی، یا مقدار دلخواه (برای تطابق با مسجد محلی)
- **قطب‌نمای سه‌بعدی** با HUD پیشرفته (فاصله و زاویه قبله، کالیبراسیون قطب‌نما)
- **اذان**: پخش خودکار صدای اذان در زمان نماز (وقتی اپ بازه) + کتابخانه صوتی (تون داخلی / افزودن از سیستم / دانلود از لینک)
- **نوتیفیکیشن بومی اذان** (۷ روزه، با `@capacitor/local-notifications`)
- **ساعت تابستانه (DST)** قابل تنظیم (برای کشورهایی که DST دارن)
- **عصر حنفی/شافعی** قابل انتخاب مستقل از روش نماز

### 🌤 هواشناسی
- پیش‌بینی بر اساس موقعیت GPS یا انتخاب شهر (۲۱ شهر سیستان و بلوچستان + شهرهای ایران)
- نمایش دما، رطوبت، سرعت باد، وضعیت آسمان
- برچسب شهر دقیق و به‌روز

### 📿 تسبیح و ذکر
- ۷ ذکر پیش‌فرض + شمارنده لمسی
- **لرزش (Vibration)** هنگام ذکر
- **استریک (Streak)** روزانه برای پیگیری تسبیح

### ⏱ ابزارها
- **کرنومتر** (start/stop/reset/lap)
- **تایمر معکوس** (پری‌ست ۱/۵/۱۰/۱۵/۳۰/۶۰ دقیقه + زمان دلخواه، دکمه شروع/توقف/ریست)
- اشتراک تصویر تاریخ

### 🌙 ماه و قمر
- **فاز ماه** با جزئیات (نام، نماد، درصد روشنایی، اطلاعات نجومی)
- مودال جزئیات فاز ماه

### 📝 یادداشت‌ها
- یادداشت محلی (localStorage) با **جستجو** و **بکاپ (خروجی/ورودی JSON)**
- **ارسال به برنامه یادداشت گوشی** (Android Notes) از طریق رابط بومی (`ACTION_CREATE_NOTE`)
- پین/دسته‌بندی/یادآوری برای یادداشت‌ها

### 🎭 فرهنگ بلوچی
- اشعار و محتوای بلوچی
- **بخش آهنگ** + **پخش صوت (TTS)** محتوای بلوچی

### 🌙 حالت شب
- **حالت شب خودکار** بر اساس غروب/طلوع خورشید (محاسبه‌شده از موقعیت)

### 🏠 ویجت اندروید
- **ویجت صفحهٔ خانه** برای نمایش اوقات شرعی روز بدون باز کردن اپ

### ⚙ تنظیمات
- اندازه فونت (کوچک/متوسط/بزرگ/خیلی بزرگ)
- موقعیت‌یاب GPS (دکمه 📍)
- زبان (فارسی / بلوچی سبک)
- نمایش نوار نماز همیشه بالا

## 🏗 نحوه بیلد (اندروید)

### پیش‌نیازها
- **JDK 17** (روی برخی دستگاه‌ها JDK 21 به دلیل محدودیت PaX اجرا نمی‌شود)
- **Android SDK** (compileSdk 36، build-tools 35.0.2)
- **Node.js 22+** و **npm**
- **Gradle 8.14+**

### مراحل
```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. همگام‌سازی وب‌اپ با اندروید
npx cap sync android

# ۳. پچ سازگاری (در صورت نیاز — JDK 17)
./patch-capacitor.sh

# ۴. بیلد APK (debug)
cd android
./gradlew assembleDebug --no-daemon
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```

> **نکته برای دستگاه‌های کم‌رم:** در `gradle.properties` مقدار `org.gradle.jvmargs=-Xmx768m` و `org.gradle.daemon=false` تنظیم شود تا از هنگ شدن جلوگیری شود.
